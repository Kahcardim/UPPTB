# Contrato responsivo

- Mobile: até 700px. Menu compacto global, coluna única, slots decorativos por lacunas entre seções.
- Tablet: 701–1024px. Navegação global desktop e composição intermediária; Alice não muda o menu em 760px.
- Desktop: acima de 1024px. Layout amplo e distribuição decorativa aleatória segura.

Exceções locais existentes (360/390/420 para conteúdo compacto; 900/980 para grids; 1100/1600 para composição ampla) não definem modos de navegação. Permanecem como ajustes de conteúdo até haver evidência de que podem ser removidas sem regressão. Cobrir especialmente 700/701/760/768 na próxima matriz física. Não alegar padronização completa de todas as media queries.
