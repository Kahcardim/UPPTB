JavaScript

Fundamentos com Beyblade

const

Algo que não deve ser reatribuído.

const game = "Beyblade X";
console.log(game);

let

Algo que pode variar.

let blader = "Robin";
blader = "Multi";

if / else

Decisão baseada em condição.

if (robinWins > 0) {
  console.log("Evento histórico");
} else {
  console.log("Robin perdeu de novo");
}

console.log()

Saída visível para entender o fluxo.

const team = "Persona";
console.log(team);

Evidência
